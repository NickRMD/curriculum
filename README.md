# Currículo Interativo
Este repositório contém um currículo interativo desenvolvido utilizando tecnologias web modernas. O objetivo é proporcionar uma experiência dinâmica e envolvente para apresentar minhas habilidades, experiências e projetos.

## Tecnologias Utilizadas
- React.js
- Vite
- Tailwind CSS

## Focando na simplicidade
O currículo foi projetado com foco na simplicidade e clareza, garantindo que as informações sejam facilmente acessíveis e compreensíveis.
